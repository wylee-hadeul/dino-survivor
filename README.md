# 🦖 공룡섬 생존기

공룡이 가득한 섬에 떨어진 주인공이 무기를 업그레이드하며 살아남는 **뱀서라이크(탕탕특공대 방식)** 모바일 웹 게임. Godot 4.6.

**플레이:** https://wylee-hadeul.github.io/dino-survivor/ (세로 화면 권장, PC도 가능)

## 조작
- **이동:** 화면 아무 곳이나 터치 후 드래그 (PC: WASD/방향키, 마우스 드래그)
- **공격:** 자동
- **탑승:** 처치로 게이지가 차면 오른쪽 아래 버튼 (PC: Space)
- **일시정지:** 오른쪽 위 버튼 (PC: Esc)

주인공은 상황마다 **한국어로 말합니다** (말풍선 + 브라우저 음성 합성). 로비에서 음성 켜기/끄기.

## 게임 구성
- **스테이지:** 5분 생존. 2:30 중간 보스, 5:00 최종 보스 → 격파 시 클리어. 시간이 지날수록 공룡이 많아지고 강해짐. 정예 공룡(보급 상자), 공룡 떼 습격 이벤트
- **레벨업:** 경험치 보석으로 레벨업 → 카드 3장 중 선택
  - 무기 8종 (최대 6개, 각 5레벨): 권총, 산탄총, 수류탄, 회전 톱날, 화염방사기, 번개, 레이저, 지뢰
  - 패시브 7종: 근력, 체력, 신발, 속사, 자석, 방탄복, 생존 지식
- **공룡 8종:** 콤프소그나투스, 랩터, 딜로포사우루스(침 뱉기), 트리케라톱스(돌진), 프테라노돈(비행), 안킬로사우루스(장갑), 파키케팔로사우루스(돌진), 스테고사우루스
- **보스:** 랩터 킹 / 트리케라 킹(중간), 티라노사우루스 / 스피노사우루스 / 브라키오사우루스 / 기가노토사우루스(최종). 돌진, 충격파, 낙석, 침 부채꼴, 점프 낙하, 부하 소환. 체력 절반 이하에서 분노
- **테마:** 고사리 숲 → 화산 지대 → 안개 늪 → 빙하 계곡 (이후 순환하며 강해짐)
- **탈것 (차고에서 골드로 구매):** 지프(기본) → 탱크(600) → 전투함(1500) → 전투기(3000, 비행 중 무적). 구매 후 강화 가능
- **아웃게임:** 골드로 영구 강화 9종(공격/체력/방어/속도/경험치/골드/흡수/탑승 게이지/부활), 차고에서 탈것 구매·장착·강화

## 개발
```bash
godot --path .                                                    # 실행
godot --path . -- --autoplay --speed=3 --shots=/tmp/s --duration=120   # 오토플레이 봇 + 스크린샷/로그
#  옵션: --fresh --god --stage=N --gold=N --skipto=SEC --chaseboss --vehicle=ID --ridefull --suicide=SEC
godot --path . res://art_preview.tscn -- --out=/tmp/art.png       # 스프라이트 시트 확인
./tools/export_web.sh                                             # 웹 빌드 (GitHub Pages: main /docs)
```
- 모든 그래픽은 코드로 그린 뒤 시작할 때 한 장의 아틀라스로 구워서 사용 (`scripts/art.gd`, `scripts/sprites.gd`)
- 오토플레이는 별도 저장 파일(`save_autoplay.cfg`)을 사용. 웹: `index.html?autoplay&stage=2&god`
